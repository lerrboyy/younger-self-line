# One Line to Your Younger Self

The single line I would send my younger self, if one line were all I got:

> You will still be awake at 4 a.m. ten years from now — only then, the night will finally be paying you back.

One sentence, one line, 108 characters. No explanation, no second sentence —
just the hour he already knows, and the twist that the night he is still
awake in will one day pay him back for staying up.

`main.ts` holds the line as a constant, checks it is 1–200 characters
(counted in Unicode code points), writes it to `/output/entry.txt`, then
reads the file back and verifies it matches exactly.
